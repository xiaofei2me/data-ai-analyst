你现在负责 data-ai-analyst 项目的第 2 个小任务。

目标：
建立 Analysis 领域的 Mock Domain。

注意：
本任务只建立数据模型和 mock 数据，不修改页面，不实现执行逻辑。

请先阅读：
- AGENTS.md
- CONTEXT.md
- frontend/src

Home

请建立 Analysis Domain。

建议目录：

frontend/src/data/domain/
  analysis.js

如果项目已有更合适的 domain/data 目录，可以遵循现有结构，但不要进行大规模目录重构。

定义：

1. Analysis

至少包含：

- id
- question
- status
- createdAt
- updatedAt
- context
- currentStep
- steps
- result
- reportId

status：

- draft
- running
- completed
- failed
- cancelled

context：

- market
- timeRange
- currency
- comparison
- dimensions

2. AnalysisStep

10 个固定步骤：

1. understanding
2. analysis_plan
3. semantic_resolution
4. data_discovery
5. trend_analysis
6. driver_analysis
7. root_cause_analysis
8. validation
9. insight_generation
10. recommendation

每个 step 至少包含：

- id
- name
- status
- dependsOn
- startedAt
- completedAt
- duration
- error

status：

- pending
- running
- completed
- failed
- cancelled

依赖关系：

understanding
→ analysis_plan
→ semantic_resolution
→ data_discovery
→ trend_analysis
→ driver_analysis
→ root_cause_analysis
→ validation
→ insight_generation
→ recommendation

3. AnalysisResult

使用当前产品确定的日本 2026 销售分析场景。

核心结果：

- market: Japan
- year: 2026
- netSales: 128.6M JPY
- yoy: -8.7%

主要驱动因素：

- Brand A: -18.2%
- Tokyo: -15.6%
- Category X: -13.4%

根因链：

Japan
→ Brand A
→ Tokyo
→ Category X

同时保留 insight 和 recommendations 字段。
