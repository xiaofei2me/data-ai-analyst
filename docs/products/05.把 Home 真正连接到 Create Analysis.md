你现在负责 data-ai-analyst 项目的第 5 个小任务。

目标：

把 Home → Create Analysis 真正串起来。

目标流程：

用户在 Home 输入：

“分析日本 2026 年销售额为什么下降，并找出主要原因”

点击开始分析后：

1. Home 获取 question
2. Home 收集 analysis context
3. 调用 Analysis Store createAnalysis()
4. Store 调用 analysisService.createAnalysis()
5. 创建 Analysis
6. 获取 analysisId
7. Router 跳转：

/analysis/:id

注意：

Home 只负责：
- 收集输入
- 创建 Analysis
- 导航

Home 不负责：
- Analysis 执行
- Step Runner
- SQL
- Agent
- Result 计算

请先阅读：
- AGENTS.md
- CONTEXT.md
- HomeView.vue
- Analysis Store
- analysisService
- Analysis Domain
- router

Home 当前如果存在：
- startAnalysis()
- startAnalysisWith()

请将其连接到真实 Store。

- market

- dimensions

market = Japan
